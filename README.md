# Java Microservices Portfolio

A hands-on Java and Spring Boot microservices project demonstrating backend engineering, API security, event-driven communication, caching, and distributed systems concepts.

This portfolio is being built incrementally. Source code and documentation will be published only after review and sanitization.

## About the Project

The goal of this project is to explore how production-oriented backend systems can be designed, implemented, secured, tested, and operated using modern Java technologies.

The application uses a commerce platform as a learning domain, with separate services for product management, order processing, inventory, and supporting capabilities.

## Technology Stack

- **Language:** Java 17
- **Framework:** Spring Boot
- **APIs:** REST
- **Microservices:** Spring Cloud, service discovery, API Gateway
- **Security:** Spring Security, JWT
- **Messaging:** Apache Kafka
- **Database:** PostgreSQL, Spring Data JPA
- **Database migrations:** Flyway
- **Caching:** Redis
- **Build:** Maven
- **Containers:** Docker
- **Observability:** OpenTelemetry, Jaeger, Prometheus, Grafana

Technologies and features will be documented as their implementations are completed and published.

## Architecture and Learning Areas

The project explores the following engineering concepts:

- Designing independent microservices with clear responsibilities
- Building REST APIs and handling service-to-service communication
- Implementing authentication and authorization
- Publishing and consuming asynchronous events with Kafka
- Managing data persistence and database migrations
- Improving performance through caching
- Handling failures, timeouts, retries, and resilience
- Observability through metrics, traces, and dashboards
- Testing, configuration management, and secure deployment practices

## Engineering Principles

This project emphasizes:

- Separation of concerns and maintainable code
- Secure API design and access control
- Idempotent processing of asynchronous events
- Clear service boundaries and data ownership
- Resilience and failure handling
- Observability and operational readiness
- Configuration and secrets management
